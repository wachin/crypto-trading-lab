# ADR-0006: Internationalization

## Status
Accepted

## Context
The application must:
* Support multiple languages
* Be maintainable for translators
* Integrate with Qt

## Decision
We use **Qt Linguist** (`.ts` files, `pylupdate6`, `lrelease`). English is the source language; other languages are translations.

## Consequences

### Positive
* Native Qt integration
* Standard workflow for Qt applications
* Translation files separate from code

### Negative
* Requires translation workflow
* UI strings must be wrapped in `self.tr()`

### Alternatives Considered
* **gettext**: More complex integration with Qt
* **Custom JSON**: Lose Qt integration
