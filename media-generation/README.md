# Crypto Trading Lab — Tutorial Media Generation

This directory contains the scripts used to generate tutorial images for the
Crypto Trading Lab Learning Center.

## Purpose

The tutorial images (used in the Learning Center lessons) are generated by
matplotlib-based scripts. This setup ensures:

1. **SVG files** are created alongside PNGs — editable in **Inkscape** for
   minor corrections (colour tweaks, label fixes, annotation adjustments).
2. **PNG files** are used by the application at runtime.
3. A clear record of *how* each image was made, so future maintainers can
   regenerate or update them without guessing.

## Usage

```bash
python3 /home/wachin/Dev3/crypto-trading-lab/media-generation/generate_tutorial_images.py
```

The script regenerates all PNG and SVG files in
`src/crypto_trading_lab/education/assets/tutorial/`.

## Regenerating after edits

1. Open the `.svg` in **Inkscape**.
2. Make your corrections.
3. Re-run the generation script (SVG is regenerated from matplotlib;
   if you need the Inkscape edits preserved, export the final SVG
   from Inkscape and overwrite the generated one, or modify the
   script to read from the Inkscape-exported SVG).

## Notes

- The SVGs are generated by matplotlib and are *not* hand-edited SVG code.
  For complex edits in Inkscape, it is often easier to edit the `.png`
  directly or modify the matplotlib script and re-run.
- The `.svg` files exist solely for editing convenience; the application
  only loads the `.png` files at runtime.
