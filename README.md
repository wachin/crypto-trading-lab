# Crypto Trading Lab

Crypto Trading Lab is a personal idea: an educational desktop application for learning how cryptocurrency markets work, without risking real money.

**Status: not yet built.** This repository does not contain a working program yet. It contains the complete project specification, prepared so that an AI Agent can build the application from scratch.

## What the finished program will be used for

Once completed, Crypto Trading Lab will let you:

- visualize cryptocurrency markets with candlestick charts;
- download and store historical market data;
- calculate technical indicators (SMA, EMA, RSI, MACD, Bollinger Bands, and more);
- create rule-based trading strategies without writing code;
- run backtests against historical data;
- practice with paper trading using simulated money;
- analyze performance and risk through clear metrics and reports;
- learn from scratch with built-in lessons, glossary, and tutorials for complete beginners.

The application is educational and uses simulation by default. Real trading is disabled in the initial version. It never guarantees profits, and it will clearly explain the risks involved in cryptocurrency trading.

## How to start the creation process

This repository is ready for an AI Agent to initiate the creation of the program. No programming knowledge is required.

Follow these steps:

1. Clone this repository to your computer.
2. Open an AI Agent (such as opencode) inside the cloned repository folder.
3. Open the `GENESIS.md` file located in the root of the repository.
4. Copy its entire contents.
5. Paste the contents into the AI Agent as a message.
6. Press **Enter**.

The AI Agent will then read the instructions and begin building Crypto Trading Lab step by step, following the detailed specifications in this repository.
